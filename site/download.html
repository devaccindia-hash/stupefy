Free. Windows 10 (version 1809) and Windows 11, 64-bit. No account, no .NET to install.

Installer

Installs for your user account without an administrator prompt (or for everyone, if you choose). Updates install themselves from inside the app.

From a terminal, once the package is in the community repository:

winget install stupefy

Upgrades: winget upgrade stupefy.

Microsoft Store

The Store edition is the same app, kept up to date by the Store. The listing goes live after certification; this card will carry the link.

Verify your download

In PowerShell, compare the printed hash with the one shown next to the installer:

Get-FileHash "$env:USERPROFILE\Downloads\Stupefy-Setup.exe"

Browser extension (Stupefy Companion)

Catches downloads, floats the "Download this video" button, sends whole pages of links. It talks only to the Stupefy app on your PC.

Chrome, Edge, Brave, Vivaldi

Version …
Download the extension (.zip)
  1. Unzip it to a folder you'll keep (for example Documents\Stupefy Companion).
  2. Open chrome://extensions (or edge://extensions), switch on Developer mode.
  3. Click Load unpacked and pick that folder.
  4. The options page opens and pairs with Stupefy in one click (Stupefy must be running).

From the stores

Edge Add-ons and Chrome Web Store listings follow; they install with one click and update on their own. Until then, the zip above is the same extension.

Requirements

Windows 10 version 1809 (build 17763) or later, or Windows 11; 64-bit. About 150 MB of disk space. Video downloads fetch yt-dlp and FFmpeg (about 140 MB) on first use.
