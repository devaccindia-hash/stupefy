# Stupefy

A fast, free download manager for Windows: up to 32 connections per file, resume after a crash, a reboot or an
expired link, a "Download this video" button on any site, queues and a scheduler. Pro is $5, once.

- **Website and download:** https://devaccindia-hash.github.io/stupefy/
- **Latest installer and browser extension:** the newest entry under [Releases](../../releases/latest)
- **What's new:** https://devaccindia-hash.github.io/stupefy/changelog
- **Privacy:** https://devaccindia-hash.github.io/stupefy/privacy

This repository holds the website (`site/`, published with GitHub Pages) and the release files. The app's source
code is developed privately; the browser extension in each release zip is plain JavaScript you can read.
